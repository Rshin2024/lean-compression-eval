On each question, higher T₀ earns a better rank. We rank each model’s geometric mean T₀ across valid measurable attempts using exact rational arithmetic. Ties share the average occupied place: two models tied for first each receive 1.5.

How the ranks are calculated

For each model and question, take the mean log₂ T₀ across valid measurable attempts, equivalent to ranking by their geometric mean T₀. Rank the same models on each shared question, with rank 1 for the highest T₀. Exact ties receive the mean of the occupied ranks. Products of the exact T₀ numerators and denominators are compared with integer arithmetic, accounting for different numbers of measurable samples. If an older report lacks exact ratios, that entire question uses a labeled log₂ fallback (tolerance 10⁻¹⁰). Then take the arithmetic mean of each model’s question ranks.

The coverage setting chooses the model cohort; only questions measurable for every qualifying model contribute. Missing or failed outputs receive no invented compression value or rank. Validity counts beside the chart retain all scheduled attempts. Changing the cohort or prompt can change the questions and rankings. A single qualifying model does not constitute a comparison.

Ranks treat small and large differences equally. Actual T₀ values remain available in cell tooltips and the magnitude view below. These are descriptive evaluation results, without uncertainty intervals; small rank differences do not establish a reliable winner.

Detailed compression measurements

T₀ = (US + UB) ÷ (WS + WB): expanded dependency-reference count per Lean source token. W is source length; U counts recursive references, including repetition. Library and tactic choices can greatly inflate expansion.

Dots show the equal-goal mean of log₂ T₀; one horizontal unit is a doubling. Each goal first averages its measurable attempts. The three prompts share the same axis.

T₀ averages log₂ T₀ within each goal, then equally across goals, and converts back. Other medians use the included measurable attempts. Coverage is shown explicitly; missing values are never replaced by zero.

Direct model-to-model comparisons

Each goal first averages the logs of its measurable model outputs; the displayed ratio gives shared goals equal weight. All selected models appear, including sparse models. Each pair can have a different set of shared goals, so these cells are descriptive comparisons, not a single overall ranking. No confidence intervals are estimated here.

Proof validity under each prompt

x/ is a count of accepted proofs, not a compression score. Each prompt has questions × attempts. Every failed or timed-out attempt stays in the denominator.

Does the compression prompt change the proofs?

Each comparison stays within one model and uses goals measurable under both prompts. A T₀ ratio of 1× means no change; 2× means twice the expanded references per source token. A proof-length ratio below 1× means shorter proof bodies.

Intervals are the original 95% theorem-family bootstrap intervals. “Unavailable” is retained for insufficient support. These comparisons use their original paired goals and are unaffected by the goal-coverage selector above.

Token usage and failure types

Totals across all attempts per model, including failures. Reasoning tokens are already included in output totals where reported. Tokenizers and effort policies differ across providers.

API costs across models

Recorded token usage priced at the frozen rate schedules. Failed and truncated generations are included. Unknown costs are unavailable, never zero; these estimates are not provider invoices.

The API subtotal covers recorded generations only. Additional retries, unresolved transport calls, taxes, credits, discounts, and unpriced calls are excluded. Reasoning is already included in billed output tokens.

Individual proof measurements

All selected models’ recorded attempts in one place. Invalid proofs and valid proofs with unavailable metrics remain visible. Source code and private reference proofs are not embedded.

Definitions and sources

WS / WB: statement / proof-body source tokens. US / UB: expanded reference counts. I₀ = WB/WS: proof length relative to statement length. D: longest dependency depth. The average question rank summarizes T₀ ordering only; it does not combine correctness, proof length and compression into an overall quality score.

Absolute compression comparisons condition on successful, measurable outputs. Use coverage or matched-goal comparisons to inspect selection effects. The shared-goal view can become empty when a selected model has very little usable output.
