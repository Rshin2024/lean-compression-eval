Measurement policy and source evidence

Each Unicode code point counts as one character. The default excludes characters identified as whitespace by the pinned measurement policy. Comments and any prose submitted in place of a proof remain included. The original response adapter removes only a complete outer wrapper; this analysis does not find or repair a proof inside mixed text.

Completed responses use the saved text passed to the evaluator, checked against the frozen adapter. Truncated responses use only preserved partial text under the same adapter and are excluded by default. Empty returned text has no measurable submission length and is never treated as a zero-length proof. It remains visible in coverage counts.

Correctness is the original Lean acceptance outcome. Pearson against this binary outcome is a point-biserial correlation; Spearman uses midranks of integer lengths. The adjusted coefficient centers length and correctness within each model × question × prompt group, excluding groups with fewer than two included attempts. It removes group mean differences only. Repeated questions, missing text and truncation can still affect these descriptive associations; no causal or held-out prediction claim is made.

Acceptance buckets use fixed doubling boundaries and include every measured attempt passing the controls. The distribution summary reports the median and middle 50% of each outcome group. The original evaluation, Wᴮ, I₀, T₀, prices and responses are unchanged.
