# Historical output

This directory is an earlier analysis of `examples/pipeline-demo` (`evaluations/v2`, reference-replay fixture), generated by a pre-2026-10-12 build of the harness. It predates the 2026-10-12 fixes (outcome taxonomy and incident accounting, reference-anchor provenance, scorer identity, failure breakdowns, per-stratum tables and the keyed `frozen_blinded_v2` audit codes), so its fields and audit bundle differ from what the current code writes. It is kept unchanged as a historical artifact. The current example report is `examples/report`, regenerated with:

```sh
PYTHONPATH=src python3 -m lean_compression analyze --run examples/pipeline-demo --version v2 \
  --references examples/demo-reference-check --output <new directory>
```
